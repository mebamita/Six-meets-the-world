It's one of my first Godot games, in which Six has to find Seven. It's a basic 2D platformer game built for Jumpstart Haven. You just have to use the left and right arrows (in pc) to move, and the space bar to jump. If you fall, you'll get spawned to the place where you begun. In the past game I built for Jumpstart Haven ('Cute Blue Little Thingo' you can find it in my Github and Itch.io), I had made the sprites and assets in Pixel Art, but for this one, i found them on the internet, to make the process quicker. I like the previous one better, but this one was a nice opportunity to refresh some things I had forgotten and to learn to organize the project better (e.g: creating more folders, I found that really useful).  

Itch.io link: https://mebamita.itch.io/six-meets-the-world
